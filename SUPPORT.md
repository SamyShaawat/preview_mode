# Support

## Where to ask

- **Question or idea:** [GitHub Discussions](https://github.com/SamyShaawat/preview_mode/discussions) (Q&A, Ideas, Show and tell).
- **Bug:** open an issue with the [bug report form](https://github.com/SamyShaawat/preview_mode/issues/new/choose). The form asks for the Odoo version, edition, other installed apps, the steps and what the popup showed.
- **Security problem:** do not open an issue. Follow [SECURITY.md](SECURITY.md).

Read the [user guide](docs/user-guide.md) first. The "What it cannot promise" section of the README lists known limits, for example a preview is an estimate and raw sockets are not blocked.

## Supported versions

One branch per Odoo version. A fix lands on `20.0` first and is ported to the others as separate pull requests.

| Odoo | Branch | Fixes |
|---|---|---|
| 20.0 | `20.0` | Yes, reference branch |
| 19.0 | `19.0` | Yes, once its port is merged |
| 18.0 | `18.0` | Yes, once its port is merged |
| 17.0 | `17.0` | Yes, once its port is merged |
| 16.0 | `16.0` | Yes, once its port is merged |

Community and Enterprise are both supported; Odoo.sh works with the repo added as a submodule. A branch whose port is not merged yet gets no fixes.

## What to include

The Odoo version and edition, the other apps installed, the exact button you clicked, what the popup showed versus what the real click did, and any red error from the browser console (F12). A screenshot helps.

This is a free project maintained in spare time; there is no support contract and no guaranteed response time.
